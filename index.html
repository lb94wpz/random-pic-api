二次元壁纸

这里是一间安静的二次元壁纸收藏室，欢迎您的到来
每张壁纸都是经过精心挑选，随手就能用
横屏铺满桌面，竖屏留给手机

简单、快速、免费的随机壁纸服务，每次访问都是一张未知的风景

API 接口

URL 说明 返回
/random 所有目录随机，按设备自动选横屏 / 竖屏 302 重定向
/random?type=moe 只在 images/moe 里随机 302 重定向
/random?type=moe,moemp 多个目录合并随机，逗号分隔 302 重定向
/random?info 各目录图片数量（首页角标用），如 147P JSON
/random?return=json JSON 返回，只含一条图片 URL JSON
/random?orientation=v 仅不传 type 时有效：强制竖屏（h 横屏 / auto 跟随设备，默认 auto） 302 重定向

快速使用

直接获取图片（适用于 img 标签、CSS 背景）

获取 JSON 数据（只含图片 URL） 

// JSON 响应示例
{
  "url": ""
}

使用示例

HTML

<img src="/random?type=moe" alt="随机壁纸">

CSS 背景

body {
  background-image: url('/random');
  background-size: cover;
}

JavaScript

fetch('/random?return=json')
  .then(res => res.json())
  .then(data => console.log(data.url));
图片格式：WebP · 自动适配横屏 / 竖屏
